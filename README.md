# iDeviceKit

Native SwiftUI iOS app for working with the libimobiledevice ecosystem. Built entirely from Windows/WSL2 + GitHub Actions macOS runners (no local Mac).

### What works in the app today (real, no simulation)
- Remote usbmuxd client (TCP, plist protocol `ListDevices`) → real device list, serial/UDID, connection type.
- Local usbmuxd socket probe (reports the real errno).
- Pairing records: structural validation, Keychain storage (this-device-only), import/export with warning. Never logged.
- In-app structured log viewer: search, level filter, pause/resume, export. **This is iDeviceKit's own log, not the device syslog.**
- JIT screen: reports whether a debugger is attached to the app itself.

### Shown as "not available" until libimobiledevice is linked
Model / iOS version / battery (lockdownd), live device syslog, diagnostics relay, crash reports, backups, image mounter, new pairing.

Read `docs/IOS_SANDBOX_FINDINGS.md` first: it explains what iOS allows.

## Layout
`iDeviceKit/App` (state) · `Views` (SwiftUI) · `Core/{Logging,Syslog,Transport,Pairing,Diagnostics}` (services; C interop layer will be added in `Core/CInterop` in M4) · `scripts/wsl` · `scripts/ci` · `.github/workflows` · `third_party` · `docs`.

## Quick start (WSL2 Ubuntu 24.04)
```bash
scripts/wsl/setup-ubuntu.sh
gh auth login
git init -b main && git add -A && git commit -m "Initial import"
gh repo create iDeviceKit --public --source . --push
scripts/wsl/trigger-ci.sh ci.yml          # Simulator build + unit tests
scripts/wsl/download-artifacts.sh ci.yml  # -> artifacts/<run>/
```
Device IPA: run the **Device archive + IPA** workflow. Without secrets it yields an unsigned IPA; for signing see `docs/SIGNING.md`.

Project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` (no `.xcodeproj` committed). Deployment target iOS 16.0 (runs on 26.2).

## Using the remote usbmuxd
On the computer with the iPhone connected: `socat TCP-LISTEN:27015,fork,reuseaddr UNIX-CONNECT:/var/run/usbmuxd`, then enter its IP in USBMux. Unencrypted; trusted network only.
